Puppeteer 使用教程

yanyue404
发布于 2025-12-03
约 17 分钟

说明

Puppeteer 是 Google 官方出品的 Node.js 库，用于通过程序完全控制 Chrome/Chromium 浏览器，实现“浏览器自动化 + 无头渲染”的一切需求。

主要功能（10 大类）

  1. 页面截图与 PDF 生成
    整页长截图、指定区域截图、生成打印级 PDF。

  2. 服务器端渲染（SSR）
    完美爬取 Vue/React/Angular 等 SPA，生成搜索引擎友好的静态 HTML。

  3. 网页自动化操作
    自动登录、填写表单、点击按钮、模拟键盘鼠标、处理弹窗、上传下载文件。

  4. 自动化测试
    UI/E2E 测试、视觉回归测试、性能测试（配合 Chrome DevTools Protocol）。

  5. 性能分析与诊断
    采集 Timeline Trace、Performance、Lighthouse 数据，分析首屏、FCP、LCP 等指标。

  6. 抓取动态内容
    等待 AJAX/图片/字体加载完成后再抓取，解决传统爬虫“抓不到数据”的痛点。

  7. 生成网站时间线与视频
    录制页面加载过程为 WebM 视频，或生成每帧截图。

  8. 测试 Chrome 扩展
    自动加载、调试、测试 .crx 扩展。

  9. 模拟各种设备与环境
    模拟手机、平板、不同分辨率、触摸事件、地理位置、语言、User-Agent、暗黑模式等。

  10. 高级 DevTools 协议调用
    可直接调用 CDP（Chrome DevTools Protocol）实现几乎所有 Chrome 开发者工具能做的操作。

简单一句话总结

Puppeteer = 可编程的 Chrome 浏览器

puppeteer 获取网页 Dom 结构

node 18 + 环境使用

npm i puppeteer@18.0.0 cheerio@1.0.0
// https://github.com/puppeteer/puppeteer/tree/v18.0.0
import Puppeteer from "puppeteer";
import { load } from "cheerio";

export const getHtmlDom = async (url) => {
  const browser = await Puppeteer.launch({ args: ["--no-sandbox"] });
  const page = await browser.newPage();
  await page.goto(url);
  const content = await page.content();

  await browser.close();
  const html = load(content); // 将 HTML 文本传递给 cheerio，创建一个类似于 jQuery 的对象

  return html;
};

puppeteer 手动安装 chromium 依赖

1. 忽略下载 chromium 安装 puppeteer

这样能先保证 puppeteer 成功安装

PUPPETEER_SKIP_CHROMIUM_DOWNLOAD=true npm install puppeteer

如果puppeteer已在package.json中，则使用

PUPPETEER_SKIP_CHROMIUM_DOWNLOAD=true npm install

2. 手动下载chromium并解压到指定目录

源码中运行的 chrome 版本

（1）node_modules\puppeteer\lib\esm\puppeteer\node\ProductLauncher.js

export function resolveExecutablePath(launcher) {
  //...
  const revisionInfo = browserFetcher.revisionInfo(_preferredRevision);
  console.log("resolveExecutablePath revisionInfo", _preferredRevision, revisionInfo);
  const firefoxHelp = `Run \`PUPPETEER_PRODUCT=firefox npm install\` to download a supported Firefox browser binary.`;
  const chromeHelp = `Run \`npm install\` to download the correct Chromium revision (${launcher._preferredRevision}).`;
  const missingText = !revisionInfo.local
    ? `Could not find expected browser (${product}) locally. ${product === "chrome" ? chromeHelp : firefoxHelp}`
    : undefined;
  return { executablePath: revisionInfo.executablePath, missingText };
}

puppeteer 通过 shell 脚本安装并启动

buildParams=$1

echo "npm install node_modules"
# 直接解压到当前目录的 node_modules 文件夹（会自动创建或覆盖）
# node_modules puppeteer 下面 .local-chromium 文件夹有两个文件夹（win64-1036745、linux-1036745）分别对应不同系统的 chrome 执行文件
rm -rf node_modules && unzip -o zip/node_modules.zip -d .


# 修复执行权限（关键！）
chmod +x node_modules/puppeteer/.local-chromium/linux-*/chrome-linux/chrome

echo "node ./src/main.js ${buildParams}"
# pwd
node ./src/main.js $buildParams;
