引言：技能生态已经大到需要"排行榜"了

Agent Skills（智能体技能）正在成为 AI 编程生态的新货币——一个带 SKILL.md 的文件夹，就能教会 Claude Code、Codex、Clawdbot 这类编码智能体一套新本领。当技能数量从几十个膨胀到成千上万个，"哪个技能值得装"就成了真实痛点。

LinklyAI/best-skills 项目应运而生：它每日聚合 skills.sh、clawhub.ai、skillhub.cn 三大技能平台的公开数据，产出三份互相补位的榜单：

榜单 回答的问题 核心指标
Best 100 综合榜 哪些技能装的人最多、最稳？ wis 综合评分（装机量 + 流行度 + 增长动量 + 社交热度加权）
Social Buzz 热议榜 过去 7 天大家在谈论什么？ buzz_score（X / Hacker News / Bluesky / GitHub 提及与互动）
Top Repos 仓库榜 哪些技能仓库最受开发者追捧？ GitHub 星标数、日增星标、收录技能数

三份榜单放在一起读，才能看到完整的生态图景：装机量代表存量实力，社交热度代表增量叙事，仓库星标代表开发者社区的长期投票。

榜单解读

榜首是个"元技能"。 find-skills 以 344.9 万装机量、74.7 的 wis 评分断层领先——它的功能就是"帮智能体找到合适的技能"。这本身就是生态成熟的标志：技能多到需要导航，而导航本身成了最热门的技能。

Microsoft 是最大的"集团军"。 全榜 100 席中，Azure 系技能（azure-ai、azure-deploy、azure-kubernetes、entra-* 等约 28 席）集体入榜，且装机量整齐地停在 58 万上下——这种高度一致的数字透露出典型的企业批量部署特征：Azure 技能包正在被组织级用户整包安装，而非开发者零散选用。

方法论教练 mattpocock 贡献 19 席。 Matt Pocock（Total TypeScript 作者）的技能不是工具，而是工程方法论：grill-me（拷问需求）、tdd（测试驱动）、handoff（任务交接）、triage（问题分诊）、code-review……把资深工程师的工作习惯封装成技能，是本榜最独特的存在。

个人开发者 steipete 占 12 席。 Peter Steinberger 在 clawhub 上的技能全是"日用工具箱"风格：weather（免 API Key 天气）、gog（Google Workspace 命令行）、slack、github、notion、obsidian、brave-search……一个顶一个厂商。

厂商全家桶成建制入榜。 Vercel 8 席（React 最佳实践、组合模式、部署）、Prisma 9 席（几乎覆盖数据库工作全流程）、Supabase / Neon 各 2 席——数据库与前端基础设施厂商已把 Skills 当成官方文档的"可执行版本"。

唯一的 skillhub.cn 入榜者是 multi-search-engine（成都智创未来）：16 个搜索引擎集成（7 国内 + 9 全球），54 万下载量，排名 60——中国平台生态的代表作。

榜单解读

"自我进化"是当下最强的叙事。 社交榜第一的 self-improving（自我反思 + 自我批评 + 自我学习 + 自组织记忆，让智能体评估自身工作并永久改进）以 0.826 的 buzz_score 断层领先；第 6 名 self-improving-agent（捕获错误与用户纠正、持续自我改进）与第 9 名 proactive-agent（从任务执行者变为主动伙伴）同属这一叙事。前十名中三席都在讲"让智能体自己变好"——这不是巧合，是社区当下真正的注意力所在。

grill-me 是 X 上的顶流。 100+ 提及（真实数字被平台截断）、4128 互动量，"让 AI 拷问你的需求再动手"的思路引发了大量开发者共鸣，连带 grill-with-docs 一起上榜。

Bluesky 是被低估的讨论场。 self-improving 在 Bluesky 上拿到 183 次命中（原始提及 383），stock-analysis（Yahoo Finance 股票/加密货币分析）虽未进前十，却在 Bluesky 拿到 199 次命中——金融分析类技能在 Bsky 社区形成了自己的小气候。

图像生成热度不低。 nano-banana-pro（Gemini 3 Pro Image 文生图/图生图）靠 28 次 X 提及贡献 2243 互动，说明"让智能体直接产出图像"的实用需求旺盛。

榜单解读

superpowers 登顶，但 mattpocock 增长最猛。 obra/superpowers（Jesse Vincent 的 SDLC 技能合集：brainstorming、TDD、subagent 驱动开发等）以 28.8 万星守住第一；但第二名 mattpocock/skills 日增 614 星，且以 53 个收录技能成为头部仓库中内容最丰富的技能库之一。

名人效应真实存在。 andrej-karpathy-skills 只有 1 个技能，却凭 Karpathy 的名字拿下 21.4 万星——社区对"Karpathy 会怎么写代码"的兴趣，本身就是一个顶级 IP。

philosophy 也能拿星。 ponytail（YAGNI / 极简主义编码哲学，日增 563 星）和 caveman（10.6 万星，"穴居人"极简 token 风格）证明：约束型技能（让 AI 少做、别过度设计）与能力型技能同样受欢迎。

安全护栏是当日最大黑马。 cloudflare/security-audit-skill 星标数刚过 1 万，但单日暴涨 2240 星，是全榜增速第一；destructive_command_guard（拦截破坏性命令）也进入百强。"给智能体系上安全带"正在成为新的刚需赛道。

收录技能数之最： NomaDamas/k-skill（7,598 星）被追踪收录了 125 个技能，是全榜数量冠军；coreyhaines31/marketingskills（62 个）、mattpocock/skills（53 个）、affaan-m/ECC（52 个）紧随其后。

中文生态在仓库榜上更活跃： JimLiu/baoyu-skills（2.6 万星，宝玉技能库）、larksuite/cli（飞书官方，28 个技能）、zenstory-ai/oh-story-claudecode（中文小说写作）、WenyuChiou/awesome-agentic-ai-zh（中文学习路线图）、op7418/Humanizer-zh（去 AI 味中文写作）——中文技能生态偏内容创作与效率办公，与英文生态的工程主导形成鲜明互补。

三榜交叉：今天值得记住的五个信号

1. 生态进入"需要导航"的阶段。
综合榜第一是 find-skills，社交榜前十有它，GitHub 提及 95 次——当选择成本超过使用成本时，聚合与发现层就成了基础设施。

2. "自我进化"从概念走向落地。
self-improving 同时打进综合榜（第 45）和社交榜（第 1），self-improving-agent 更是以 120.9 万下载冲进综合榜第 55。让智能体记录错误、自我批评、永久改进，是当前增长最快的品类。

3. 方法论比工具更有黏性。
mattpocock 系（grill-me / tdd / handoff / triage）三榜全部在榜：装机 19 席、社交榜 4 席（含前二占据两席）、仓库榜第 2 且日增最高。"教会 AI 怎么干活"胜过"替 AI干活"。

4. 厂商集团军与个人奇兵并存。
Microsoft 28 席、Vercel 8 席、Prisma 9 席的集团军打法，与 steipete 一人 12 席、obra 一仓库 28.8 万星的双轨并行——企业看重整包分发，开发者用星标投票给个人品牌。

5. 平台三足鼎立格局初现。
skills.sh 占综合榜约 3/4 席位，是存量主战场；clawhub.ai（Clawdbot 生态）以日用工具和自我进化类技能见长；skillhub.cn 尚在早期，但 multi-search-engine 的 54 万下载和仓库榜上的中文军团，预示着下一个增量市场。

obra/superpowers 榜单表现（仓库榜第 1）

仓库地址：github.com/obra/superpowers（288,126 星 · 日增 331 · 收录 14 个技能）

superpowers 的技能级明细未进入技能榜统计，但其 SDLC 全流程技能集覆盖（据仓库主题标签：brainstorming / sdlc / subagent-driven-development）：brainstorming（实现前强制需求探索）、writing-plans / executing-plans（计划先行）、test-driven-development、systematic-debugging、verification-before-completion（先有证据再宣布完成）、requesting / receiving-code-review、subagent-driven-development、dispatching-parallel-agents（并行子代理）、using-git-worktrees（隔离工作区）、finishing-a-development-branch（分支收尾流程）。

查漏补缺建议：两家在 TDD、debug、code-review 上功能重叠——建议以 superpowers 的流程链为主干（brainstorming → writing-plans → executing-plans → verification），用 mattpocock 的差异化技能补位：需求拷问（grill-me / grilling）、领域建模（domain-modeling / codebase-design）、任务交接（handoff）、调研（research）——这四个能力是 superpowers 未覆盖、而 mattpocock 数据最强的部分。

通用建议

  1. 从 find-skills 开始（综合榜第 1，344.9 万装机）：让智能体自己学会找技能，一次安装解决长期发现成本。
  2. 方法论 ≤ 5 个 + 工具按需：方法论类技能会改变智能体的行为模式，装太多容易互相冲突。
  3. 关注 anomaly 标记：数据中带 anomaly 标记的技能（如部分 Azure 系装机量高度一致的批量部署特征）需留意真实使用量与统计口径的差异。
  4. 中文用户可关注：skillhub.cn 的 multi-search-engine（54 万下载）+ 仓库榜中文军团（baoyu-skills、larksuite/cli、Humanizer-zh 等）。

结语

三份榜单合起来读，Agent Skills 生态的今天大致是这样一个画面：存量看厂商与方法论，增量看自我进化与安全护栏，长期看社区星标与个人品牌。

技能市场正在重演应用商店的历史——从"有什么装什么"走向"排行榜决定装什么"。而 best-skills 这样的每日聚合项目，正在成为这个新兴市场的"App Annie"。
